# Bug Bank: Testes Manuais

Projeto de testes manuais dos módulos de **cadastro** e **login** do
[Bug Bank](https://bugbank.netlify.app), aplicação criada para
prática de QA, com falhas propositais.

## Objetivo
Praticar a elaboração de casos de teste, a execução com evidências e o
registro de bugs.

## Escopo
- Cadastro de usuário
- Login de usuário

## Casos de teste

| ID | Cenário | Status |
|---|---|---|
| CT-001 | Cadastro com sucesso | Passou |
| CT-002 | Cadastro com senhas divergentes | Passou |
| CT-003 | Cadastro com e-mail em formato inválido | Passou |
| CT-004 | Login com sucesso | Passou |
| CT-005 | Login com campos obrigatórios vazios | Passou |
| CT-006 | Login com usuário não cadastrado | Passou |

## Conteúdo do repositório
- `casos-de-teste-bugbank.pdf`: documento completo com passos e resultados
- `evidencias/`: prints da execução dos testes
